# mini-cam-esp32
A tiny camera running on an esp32 displaying a live review to a screen.
Ich will eine Kamera mit einem esp32, bildschirm und ein paar knöpfen bauen. Ich will einen 2inch LCD Display modul benutzen, da er ca. 5 cm. groß ist, 240 auf 320 pixel hat und nur 16 Euro kostet. Für den esp habe ich mich für einen von esp32-S3 von freenove entschieden, da er eine kamera und sd karten slot eingebaut hat und 8 MB PSram hat, was für einen flüssigen video stream sorgen wird. Leider kostet er 21 Euro aber dafür hat er schon fast alles inklusive was ich benötige. Die fertige kamera soll bilder, sowie flüssige viedos (ohne ton) aufnehmen können. Da ich einen 3d drucker zuhause habe und schon etwas geübt in tinkercad bin sollte das gehäuse auch kein problem sein. Verbinden werde ich die teile mit draht und einem alten weller von meinem vater.
